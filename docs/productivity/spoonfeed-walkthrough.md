## What it does

`spoonfeed-walkthrough` writes a story-by-story walkthrough of one flow and prepares the world so the reader only runs the feature. The agent handles setup, identity, seed data, and id capture. Every request in the document is exact. Every story ends on what the reader should see.

## When to reach for it

Use it when someone asks to be onboarded on a flow, wants exact payloads, or says not to assume they already know the setup. It is the wrong tool for a whole-repo map or for implementation work.
