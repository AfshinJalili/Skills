## What it does

`goal` attaches one completion condition to the work and keeps going until the transcript can prove it, the work is blocked, or the budget runs out. The condition is an acceptance test: one measurable end state, the check that proves it, and the constraints that must hold on the way.

## When to reach for it

Type `/goal`. Use it for a long unattended run toward a verifiable result. A small edit does not need one.

`/goal status`, `/goal pause`, `/goal resume`, and `/goal clear` read or stop the goal that is already set. Only you invoke it.
